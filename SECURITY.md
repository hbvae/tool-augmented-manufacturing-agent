# Security Policy

This repository contains research software and synthetic data only.

## Do not report publicly

Do not open a public issue containing API keys, access tokens, internal URLs, local file paths, personal information or real production data. Revoke exposed credentials immediately through the relevant provider.

## Operational scope

The released tools are designed for read-only analysis. They are not authorized to write to MES, ERP, QMS, warehouse or equipment-control systems. High-risk decisions require independent validation and human approval.
